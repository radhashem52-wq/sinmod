# Movie Rating Prediction

## معرفی پروژه
توی این پروژه سعی کردم با استفاده از یادگیری ماشین، امتیاز فیلم‌ها رو بر اساس چند ویژگی مثل بودجه، محبوبیت، مدت‌زمان فیلم و تعداد رأی‌ها پیش‌بینی کنم.

برای انجام پروژه از دیتاست TMDB 5000 Movies استفاده کردم که شامل اطلاعات ۴۸۰۳ فیلمه. اول داده‌ها رو بررسی کردم و چند نمودار برای شناخت بهتر اطلاعات رسم کردم. بعد از آماده‌سازی داده‌ها، چند مدل مختلف رو آموزش دادم و نتایجشون رو با هم مقایسه کردم.

## مدل‌های استفاده‌شده
برای پیش‌بینی امتیاز فیلم از این سه مدل استفاده کردم:

- Linear Regression
- Random Forest Regressor
- K-Nearest Neighbors (KNN)

همچنین برای یک بخش طبقه‌بندی، فیلم‌هایی که امتیازشون بیشتر از ۷ بود از بقیه جدا شدن و سه مدل طبقه‌بندی هم بررسی شدن.

## نتیجه مدل‌ها
بعد از مقایسه مدل‌های رگرسیون، Random Forest بهترین نتیجه رو روی داده‌های آزمون به دست آورد.

| مدل | MAE | RMSE | R² |
|---|---:|---:|---:|
| Random Forest | 0.5938 | 0.8195 | 0.5546 |
| KNN | 0.6934 | 1.0353 | 0.2892 |
| Linear Regression | 0.7021 | 1.1018 | 0.1950 |

این نتیجه نشون می‌ده که مدل Random Forest در این پروژه عملکرد بهتری نسبت به دو مدل دیگه داشته؛ البته پیش‌بینی‌ها همیشه دقیق نیستن.

## بخش عملی پروژه
در نوت‌بوک، یک بخش برای پیش‌بینی امتیاز فیلم قرار داده شده. کاربر می‌تونه اطلاعاتی مثل بودجه، محبوبیت، مدت‌زمان فیلم و تعداد رأی‌ها رو وارد کنه و امتیاز تخمینی فیلم رو از مدل بگیره.

## محدودیت‌ها
این مدل فقط از چهار ویژگی استفاده می‌کنه، بنابراین عوامل دیگه‌ای که ممکنه روی امتیاز فیلم تأثیر بذارن در نظر گرفته نشدن. همچنین تعداد رأی‌ها و محبوبیت معمولاً بعد از انتشار فیلم مشخص می‌شن؛ به همین دلیل، مدل برای پیش‌بینی فیلم‌های تازه‌منتشرنشده محدودیت داره.

## جمع‌بندی
در این پروژه مراحل بررسی داده‌ها، رسم نمودارها، آموزش مدل‌های یادگیری ماشین و مقایسه نتایج انجام شد. در نهایت، مدل Random Forest برای پیش‌بینی امتیاز فیلم‌ها نتیجه بهتری داشت و از اون در بخش عملی پروژه استفاده کردم.
